Финальный этап. Нам нужно подготовить проект "Аптека" к развертыванию в Docker и деплою на Render.com.

Твоя задача:

    Написать оптимизированный Dockerfile для Django-приложения (используй python:3.11-slim, настрой gunicorn).

    Создать docker-compose.yml для локального запуска, включающий в себя контейнер с веб-приложением и контейнер с базой данных PostgreSQL (для тестирования прод-окружения локально).

    Модифицировать settings.py: база данных должна переключаться на PostgreSQL, если в окружении есть переменная DATABASE_URL (используй dj_database_url), иначе использовать локальный SQLite.

    Написать пошаговый гайд: какие переменные окружения нужно задать в панели Render.com (DATABASE_URL, SECRET_KEY, ALLOWED_HOSTS, LOG_LEVEL), и какую Build Command указать (pip install -r requirements.txt && python manage.py migrate), чтобы успешно захостить проект.

Предоставь Dockerfile, docker-compose.yml и инструкции по настройке деплоя.
